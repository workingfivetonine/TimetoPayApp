# TimetoPay — Instagram Post Designs (12-post launch set)

> Copy/paste-ready posts that map 1:1 to the 30-day calendar in `docs/marketing/plan.md`.
> Each post has: the visual design spec, the on-image text, the full caption, and hashtags.
> Build in Canva with brand kit **`kAHLVoeL-zI`**. A ready-to-publish visual mockup of all
> 12 is linked at the bottom.

## Brand system (use for every post)

| Token | Hex | Use |
|---|---|---|
| Primary purple | `#7c3aed` | headlines, buttons, key numbers, brand bar |
| Deep purple | `#5b21b6` | secondary text, accents |
| Ink (text) | `#1e1b2e` | body copy on light backgrounds |
| Soft lilac bg | `#faf8ff` | card / post background |
| White | `#ffffff` | cards, receipt mockups |
| Lilac tint | `#ede9fe` / `#f3f0ff` | chips, highlight blocks |
| Rose (alert) | `#f43f5e` / `#e11d48` | "overpaying" / high-spend callouts ONLY |

- **Font:** Inter (the app's font) — Bold for headlines, Regular for body.
- **Logo:** `assets/images/logo-lockup.png` — bottom-left or bottom-center, small.
- **Format:** 1080×1350 (4:5 portrait — Instagram's largest feed footprint). Reels 1080×1920.
- **Consistency rule:** every post has the small purple brand bar + logo so the grid looks like one system.

## POST #1 — Reel — "POV: you've been overpaying"
- **Type:** Reel (1080×1920), 8–12 sec.
- **Storyboard:**
  1. (0–2s) Text on lilac bg: *"POV: you just found out you've been overpaying for groceries 😳"*
  2. (2–6s) Screen-record: open app → tap scan → point at a real receipt → items + prices populate.

## Production notes
- **Batch it:** design all 12 in one Canva session using the brand kit; duplicate one master 1080×1350 frame so spacing/logo stay identical.
- **Reels first:** the 4 Reels (#1, #4, #7, #10) drive the most reach — record them once with real app footage, they're reusable on TikTok verbatim.
- **Alt text:** add for accessibility (describe the screen + the savings number).
- **Never fake:** no invented testimonials, no unsourced stats (see Post #9). Use real numbers from your own analytics or a citable source.
